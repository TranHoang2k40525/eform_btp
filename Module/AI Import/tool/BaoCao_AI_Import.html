Báo cáo hoàn thiện công cụ AI Import Excel

Mục tiêu: chuẩn bị dữ liệu và prompt để AI hiểu cấu trúc chỉ tiêu thống kê; ánh xạ đúng cấp; trả JSON hợp lệ; đồng thời cung cấp quy trình tạo dataset và huấn luyện model có thể chạy lại.

Không sửa file C#

1. Phạm vi khảo sát

  • Đã đọc tài liệu Markdown của dự án, tài liệu thiết kế dataset và module AI Import.
  • Đã tham khảo luồng import Excel cũ từ các file JavaScript/HTML/config do hệ thống cung cấp.
  • Chỉ phân tích hai workbook đại diện trong Data/Raw; không quét toàn bộ Raw và không đọc __pycache__.
  • Giữ nguyên toàn bộ mã C#, project .NET và cấu hình tích hợp hiện có.

5. Cần làm gì để có dataset đủ điều kiện huấn luyện?

  1. Đặt workbook .xlsx/.xlsm vào Module/AI Import/Data/Raw; bỏ qua file khóa bắt đầu bằng ~$.
  2. Chuẩn bị catalog field eForm tại Data/Labels/eform_fields.jsonl. Catalog phải có DocType, DataFieldId, tiêu đề field, mã cột và header path.
  3. Chạy notebook 01_BuildDatasetComplete.ipynb từ trên xuống để quét cấu trúc header và tạo candidate.
  4. Mở tool/work/Labels/mappings.jsonl và duyệt từng dòng. Điền target_data_field_id, target_field_name, target_field_title, target_column_code.
  5. Chỉ với nhãn đã kiểm tra thật, đặt verified=true và verification_method thành human, reviewed hoặc curated. Dòng không phải dữ liệu đặt ignore=true.
  6. Chạy lại notebook 01. Notebook tạo query/positive/hard-negative, chia theo workbook và kiểm tra rò rỉ dữ liệu.
  7. Kiểm tra báo cáo thống kê cuối notebook. Phải không có label conflict, các split không giao nhau và test input không chứa đáp án.
Lưu ý: candidate_fields chỉ là gợi ý. Không đặt verified=true hàng loạt nếu chưa có người kiểm tra, vì model sẽ học lại lỗi ánh xạ.
Trạng thái dữ liệu hiện có: file mapping nguồn chứa 14.649 candidate, trong đó 87 dòng legacy có target nhưng thiếu verification_method. Notebook chủ động đưa các dòng này về hàng chờ duyệt; nếu chúng thực sự đã được người kiểm tra, cần bổ sung verification_method="human" hoặc "reviewed".

6. File huấn luyện model

File phải chạy sau notebook 01: 02_TrainModelFromDataset.ipynb

Notebook huấn luyện không đọc nhãn thô. Nó chỉ đọc bốn file do notebook 01 sinh ra, kiểm tra schema và rò rỉ workbook, sau đó fine-tune BAAI/bge-m3 bằng query, positive và tối đa bốn hard negative.

  1. Nếu dùng Colab: tải toàn bộ repository lên Drive, mở notebook, đặt RUN_ON_COLAB=True và bật GPU.
  2. Nếu chạy local: mở notebook từ repository; đường dẫn được dò tự động. Chỉ dùng MODULE_ROOT_OVERRIDE khi notebook nằm ngoài dự án.
  3. Chạy tất cả cell. Notebook dừng an toàn nếu có dưới 20 mẫu train hợp lệ.
  4. Model được lưu ở tool/artifacts/model/EFormExcelMapper-v1; metric validation nằm trong training-metrics.json.
  5. Sau đánh giá test, cấu hình service bằng biến AI_IMPORT_EMBEDDING_MODEL trỏ tới model đã duyệt.

7. Prompt và JSON contract

  • Prompt hierarchy mapping
  • JSON Schema đầu ra
  • 7 mẫu curated/hard-negative
  • Request mẫu

Embedding model học ánh xạ header Excel → DataField. LLM hierarchy mapping vẫn dùng prompt + validator JSON để kiểm soát cấp cha/con; hai lớp bổ trợ nhau và không nên thay thế lẫn nhau.
