KẾ HOẠCH XÂY DỰNG EFORMEXCELSTRUCTUREEXTRACTOR-V1
Phiên bản: 1.0
Phạm vi: AI local trích xuất cấu trúc Excel và trả dữ liệu xem trước; không dùng LLM; không mapping DataField; không ghi document.

======================================================================
1. MỤC TIÊU CUỐI CÙNG
======================================================================

Đầu vào:
- File .xlsx hoặc .xlsm thuộc nhóm biểu thống kê tương tự Data/Raw.

Đầu ra trước khi người dùng bấm "Nhập dữ liệu":
- Danh sách sheet.
- Một hoặc nhiều vùng bảng trên mỗi sheet.
- Tọa độ bắt đầu/kết thúc bảng.
- Các dòng header nguyên bản.
- Merged cells, mã cột, header_path và kiểu dữ liệu suy luận.
- Ma trận value giữ nguyên thứ tự hàng/cột.
- Cảnh báo và confidence về cấu trúc.

Ngoài phạm vi model:
- Không nhận hoặc hiểu DocumentContent.
- Không chọn target DataField.
- Không tạo FormConfig, ValueData hoặc SourceData.
- Không kiểm tra required, sum rule, readonly, quyền người dùng.
- Không post dữ liệu vào document và không ghi database.

======================================================================
2. KIẾN TRÚC ĐƯỢC CHỌN
======================================================================

Tên model: EFormExcelStructureExtractor-v1
Loại model: mô hình sequence tagging/multi-task nhỏ chạy local.

Đầu vào model là chuỗi các dòng/ô đã được parser Excel biến thành feature:
- vị trí row/column;
- kiểu ô text/number/date/formula/blank;
- mẫu ký tự như A, B, (1), (2), I, 1, 1.1;
- merged span;
- bold, alignment, border, fill, number format;
- mật độ ô trống và ô có dữ liệu;
- feature hàng trước/hàng sau và cột lân cận.

Nhãn model:
- TITLE: tiêu đề báo cáo;
- METADATA: đơn vị, kỳ báo cáo, biểu số;
- HEADER: header thường/nhiều tầng;
- COLUMN_CODE: dòng mã A, B, (1), (2), ...;
- DATA: dòng dữ liệu;
- FOOTER: chữ ký, người lập biểu, ghi chú cuối;
- NOTE: ghi chú trong/ngoài bảng;
- BLANK: dòng/ô rỗng;
- TABLE_SEPARATOR: ranh giới giữa hai bảng.

Model không phát sinh text hoặc số mới. Sau khi model dự đoán nhãn, code xác định sẽ cắt bảng, dựng header_path và copy raw_value/display_value/formula từ workbook.

7. GIAI ĐOẠN 4 - XÂY VÀ HUẤN LUYỆN MODEL (TUẦN 4-5)
======================================================================

Kiến trúc v1 đề xuất:
- Cell feature encoder.
- Row pooling encoder.
- 2-4 Transformer encoder layers theo chuỗi dòng trong sheet/window.
- Multi-task heads: row_role, cell_role, table_boundary.
- Quy mô nhỏ, mục tiêu chạy CPU; không sử dụng LLM.

Loss:
- Weighted cross-entropy cho class mất cân bằng.
- Boundary loss tăng trọng số cho header_start, data_start và table_end.
- Consistency loss nhẹ để hạn chế chuỗi nhãn vô lý, ví dụ FOOTER → DATA → TITLE.

Huấn luyện:
1. Chuẩn hóa feature và vocabulary ký tự/domain.
2. Train với early stopping theo whole-table exact match trên Validation.
3. Dùng class weight hoặc balanced sampler cho DocType/layout hiếm.
4. Không chọn checkpoint theo training loss.
5. Lưu model, feature config, label map và dataset version cùng nhau.

Đầu ra:
- model.onnx hoặc model.pt.
- feature_config.json.
- label_map.json.
- training_metrics.json.
- model_card.md.

======================================================================
9. GIAI ĐOẠN 6 - ĐÁNH GIÁ ĐỘC LẬP (TUẦN 6)
======================================================================

Metric bắt buộc:
- Row-role macro F1.
- Table detection precision/recall/F1.
- Header boundary exact match.
- Data boundary exact match.
- Column count exact match.
- Merge reconstruction F1.
- Header text preservation.
- Cell value preservation.
- Whole-table exact match.
- Workbook success rate.
- Latency p50/p95 và memory.

Mục tiêu nghiệm thu đề xuất, phải đo chứ không tuyên bố trước:
- Cell value preservation = 100%.
- Header text preservation = 100% đối với ô đã chọn đúng.
- Table detection F1 >= 0,98 trên Test thuộc phạm vi.
- Header/data boundary exact match >= 0,95.
- Whole-table exact match >= 0,95 trên test độc lập.
- File confidence thấp không được tự động coi là thành công.

======================================================================
10. GIAI ĐOẠN 7 - TÍCH HỢP PREVIEW (TUẦN 7)
======================================================================

API đề xuất:
POST /api/excel/extract
Input: file
Output: PreviewData v1.0

Luồng frontend:
1. Upload file.
2. Hiển thị sheet/table mà model phát hiện.
3. Render header_rows + merged_cells + rows vào Handsontable.
4. Người dùng chọn/sửa vùng nếu cần.
5. Chỉ khi bấm "Nhập dữ liệu", frontend mới lấy DocumentContent/FormConfig.
6. Frontend chạy mapping/validation hiện có và gửi IMPORT_EXCEL_DONE.

Điều kiện hoàn thành:
- API extract hoạt động không cần documentId.
- Preview không thay đổi document.
- Đóng preview hoặc lỗi model không gây thay đổi dữ liệu eForm.
